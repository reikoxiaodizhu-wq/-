# Far East Europe Restaurant Monthly Report

High-end magazine-style monthly report website built with React + TypeScript + Vite + Tailwind CSS.

Features
- Mobile-first, responsive
- Hero cover with European city night imagery
- Navigation with smooth scroll and active-section highlight
- Restaurant News: card layouts, price, tags and status
- New Resources: image-led cards (Unsplash source)
- Resource updates timeline
- Featured restaurants (alternating layout)
- Closure notice (full width red theme)
- Realtime search & country filter (Austria, Germany, Hungary, Italy, Poland)
- Dark mode toggle
- Back to top button
- Framer Motion animations
- Icons via Lucide

Run locally
1. npm install
2. npm run dev

Notes
- Images use https://source.unsplash.com/ for easy demo (no API key required).
- Tailwind dark mode uses the `class` strategy.
